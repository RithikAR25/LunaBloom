# Architecture Decision Records (ADRs)

Welcome to the LunaBloom ADR log. 

As a senior-level portfolio project, LunaBloom documents significant architectural and engineering decisions using this directory. 

ADRs explain the **"Why"** behind the code. They provide crucial context for recruiters, engineering managers, and developers reviewing this repository, proving that our technological choices are driven by business requirements (privacy, offline capability, performance) rather than arbitrary preference.
