# Security Policy

LunaBloom is a privacy-first health application. We take the security of personal health information (PHI) and our offline-first SQLite implementation extremely seriously.

## Supported Versions

Currently, only the latest release of LunaBloom receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within LunaBloom, please do **not** open a public issue on GitHub. 

Instead, please send an email privately with the details of the vulnerability. We will endeavor to respond to your report within 48 hours.

**Please include the following in your report:**
- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact on user data or privacy.

We appreciate the efforts of security researchers who help keep LunaBloom secure!
