# Contributing to LunaBloom

Thank you for your interest in LunaBloom!

## Portfolio Status

This repository showcases engineering practices and serves as a portfolio project. 

Because this repository accurately reflects the author's individual engineering capabilities, we are **not** accepting pull requests or external contributions from the community.

## Reporting Issues
If you are reviewing the app and notice a bug, typo, or have a feature idea, you are welcome to open an Issue using our standard `.github/ISSUE_TEMPLATE` forms. However, please do not submit a Pull Request to fix it yourself, as it will be closed without merging.

Thank you for understanding and respecting the purpose of this repository!
